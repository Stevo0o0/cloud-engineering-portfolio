## Featured Projects

### 1. AWS EC2 Infrastructure Deployment and Monitoring with Terraform

**Repository:** [terraform-aws-ec2-monitoring](https://github.com/Stevo0o0/terraform-aws-ec2-monitoring)

Provisioned and configured an Ubuntu-based EC2 web server using Terraform. The project includes an S3 remote state backend, security group rules, Bash-based Apache web server setup, and a CloudWatch CPU utilization alarm.

**What this demonstrates**
- Infrastructure provisioning with Terraform
- AWS compute, networking, and storage fundamentals
- Remote Terraform state management using S3
- Server configuration with Bash
- Basic infrastructure monitoring with CloudWatch

**Technologies:** AWS EC2, S3, CloudWatch, Terraform, Bash, Ubuntu, Apache

### 2. Ansible Multi-Server Provisioning

**Repository:** [ansible-multi-server-provisioning](https://github.com/Stevo0o0/ansible-multi-server-provisioning)

Used an Ubuntu control node to automate configuration across four managed Linux servers running Ubuntu and CentOS. The playbooks install and configure Chrony, account for operating-system differences, and manage the relevant services.

**What this demonstrates**
- Ansible inventories, playbooks, variables, and facts
- Cross-platform configuration using conditional tasks
- Linux package and service management
- Repeatable configuration across multiple servers

**Technologies:** Ansible, AWS EC2, Linux, Ubuntu, CentOS, YAML, SSH
